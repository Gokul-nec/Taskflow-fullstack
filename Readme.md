# TaskFlow

A simple and scalable **task management application** built with **React.js, Express.js, PostgreSQL, Prisma, and JWT authentication**.  
Designed to be clean, secure, and easy to manage your tasks.

---

## 🚀 Features

- JWT-based authentication (access & refresh tokens)
- User registration and login
- Task CRUD operations
- Task filtering by status, priority, category, and due date
- Secure password hashing with bcrypt
- Prisma ORM with PostgreSQL
- Centralized error handling
- Input validation
- CORS enabled

---

## 🛠 Tech Stack

- React.js
- Node.js
- Express.js
- PostgreSQL
- Prisma ORM
- JWT Authentication
- bcrypt
- dotenv
